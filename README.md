# ماهک

اپلیکیشن کاملا آفلاین ثبت چرخه قاعدگی، علائم، حس و حال روزانه، ثبت یادآوری برای داروها، ثبت تاریخچه وزن، محاسبه روز‌های تخمک‌گذاری و PMS. کاملا فارسی و برای سیستم عامل اندروید.

![maahak banner](./assets/maahak-banner-fa.png)

## حریم خصوصی

اطلاعات و داده‌های جمع آوری شده در برنامه شامل تمامی، چرخه‌های قاعدگی، علائم، وزن، یادداشت‌ها و یادآورها بر روی دستگاه موبایل ذخیره می‌شوند. برنامه ماهک هیچ حساب کاربری یا سرویس اینترنتی ندارد. این برنامه هیچ رمزگذاری جداگانه بر روی پایگاه داده یا قفل داخل برنامه ندارد به همین دلیل نحوه نگهداری از داده‌های وارد شده به عهده خود کاربر می‌باشد.

محاسبه تاریخ‌های قاعدگی، PMS و تخمک‌گذاری تخمینی‌اند؛ مخصوصاً برای چرخه‌های نامنظم ممکن است دقیق نباشند. این برنامه روش پیشگیری از بارداری یا ابزار تشخیص بارداری نیست.

## نکته برای نوتیفیکیشن

برای نمایش نوتیفکیشن‌های یادآوری‌های بخش دارو، برنامه نیاز به داشتن دسترسی به نوتیفیکیشن اندروید است، که نیاز است کاربر این دسترسی را به برنامه بدهد.

## توسعه برنامه

برای توسعه برنامه به این موارد نیاز است:

```sh
node.js v22 above
pnpm (nodejs package manager)
```

این پروژه از Expo SDK 58 استفاده می‌کند و حداقل نسخه مربوط به React Native نسخه 0.88.1 است.

برای نصب پکیج‌ها و اجرای برنامه در محیط توسعه:

```sh
pnpm install
pnpm start
```

برای اجرای برنامه روی شبیه‌ساز یا گوشی اندروید:

```sh
pnpm android
```

## اطلاعات کلی پروژه

- الگوهای دیتابیس: `src/db/schema.ts`
- ریپازیتوری‌ها: `src/db/repository.ts`
- متن‌های فارسی برنامه: `src/i18n/fa.json`
- انتخاب تاریخ‌ها با تقویم شمسی انجام می‌شود.
- برای تولید مایگریشن‌ها: `pnpm db:generate`
- بررسی TypeScript: `pnpm typecheck`
- تست‌های برنامه: `pnpm test`
